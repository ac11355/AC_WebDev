Checkbox Groups

Check boxes allow the user to select more htan one value at once. Grouped checkboxes (aka for the same answer) all share the same name attribute. The value attribute is what gets sent to the server if that check box is checked.


Radio Groups

Radio Groups allow the user to select only one value from a set of options. Grouped radio buttons (aka for the same answer) all share the same name attribute. The value attribute is what gets sent to the server if that radio button is selected.
